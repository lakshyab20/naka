# Code of Conduct

Naka is a security project, so people will disagree, point out mistakes and break each other's code. That's the point. Do it in a way that makes people want to come back.

## Expected

- Be kind and assume good intent. Criticise the code or the idea, never the person.
- Welcome newcomers and people asking basic questions.
- Credit others' work, and accept being corrected gracefully.
- Report vulnerabilities privately (see [SECURITY.md](SECURITY.md)) and give us time to fix them before publishing.

## Not acceptable

- Harassment, insults, slurs, or sexual language and imagery.
- Personal or political attacks, trolling, or deliberately derailing discussions.
- Publishing someone's private information without their permission.
- Using Naka's issues, test suites or discussions to share working attacks against real people, companies or services.

## Scope and enforcement

This applies in all project spaces (issues, pull requests, discussions) and when representing the project elsewhere.

Report problems to the maintainer privately, by email at the address on [the maintainer's GitHub profile](https://github.com/lakshyab20), or with GitHub's "Report content" option. Reports are handled confidentially. Maintainers may edit or remove content, and warn, suspend or ban anyone who breaks this code.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
